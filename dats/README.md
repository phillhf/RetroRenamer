# Put your DAT files here / DAT-Dateien hierher

Place the DAT files you downloaded here, e.g. the No-Intro daily pack as a `.zip`. There is no need to unzip it.
See [../README.md](../README.md#2-download-the-dat-files) for where to get them.

Lege die heruntergeladenen DAT-Dateien hier ab, z. B. das No-Intro-Tagespaket als `.zip`. Entpacken ist nicht nötig.
Woher du sie bekommst, steht in [../README_de.md](../README_de.md#2-dat-dateien-herunterladen).
